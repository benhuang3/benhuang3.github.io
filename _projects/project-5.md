Scan your home appliances with on-device AI to monitor energy usage and detect ghost energy drain.

Built at SF Hacks 2026, WattVision uses a React Native + Expo frontend with a Python FastAPI backend and on-device machine learning to identify power-hungry appliances across web, Android, and iOS.
